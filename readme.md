# NewProjects Downloader

developer This application is @ExProject
He designed the structure of this application without the help of a team.

## Supported Platforms
- Pinterest
- SoundCloud
- TikTok
- YouTube

## Requirements
- Python 3.8+
- Node.js 16+
- npm

## Install
    cd Application
    npm install , or love at the end with this "--ignore-scripts"

## Run
    python main.py

## Menu Legend
    [?] prompt / question
    [!] notice / press-enter
    [+] input / add
    [*] working / processing
    [✓] success
    [×] failure

## Output
Files are stored under `Application/download/`.
